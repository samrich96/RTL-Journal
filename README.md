# RTL Journal

Responsive React implementation of the RTL Journal Discover home page from Figma.

## Stack

- React 19 + Vite
- Lucide React (icons)
- CSS modules-style component styles (no Tailwind)

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run preview` — preview production build
